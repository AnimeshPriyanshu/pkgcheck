# pkgcheck Examples

This directory contains real terminal output from running `pkgcheck` against the test fixtures included in the repository. All output was generated by the actual CLI — nothing is fabricated.

## Prerequisites

```bash
# Install pkgcheck in development mode
pip install -e ".[dev]"

# For AI explanations (optional): start LM Studio with google/gemma-4-e4b
# The examples below show fallback explanations when LM Studio is unavailable
```

## Test Fixtures

The examples use two fixture directories in `tests/fixtures/`:

- **Clean fixture** (`tests/fixtures/clean/`): A package that matches its source exactly — no suspicious findings.
- **Poisoned fixture** (`tests/fixtures/poisoned/`): A package with supply-chain tamper indicators:
  - Unexpected `postinstall` script in `package.json`
  - Unknown file `setup.js` present only in the package

## Reproducing All Examples

Run all examples sequentially:
```bash
#!/bin/bash
set -e

echo "=== Clean package (table) ==="
python -m pkgcheck -p tests/fixtures/clean/package -s tests/fixtures/clean/source

echo -e "\n=== Clean package (JSON) ==="
python -m pkgcheck -p tests/fixtures/clean/package -s tests/fixtures/clean/source --json

echo -e "\n=== Poisoned package (table) ==="
python -m pkgcheck -p tests/fixtures/poisoned/package -s tests/fixtures/poisoned/source

echo -e "\n=== Poisoned package (JSON) ==="
python -m pkgcheck -p tests/fixtures/poisoned/package -s tests/fixtures/poisoned/source --json

echo -e "\n=== Poisoned package (JSON with explanations) ==="
python -m pkgcheck -p tests/fixtures/poisoned/package -s tests/fixtures/poisoned/source --json --explain

echo -e "\n=== Clean package with --explain ==="
python -m pkgcheck -p tests/fixtures/clean/package -s tests/fixtures/clean/source --explain
```
